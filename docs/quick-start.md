## Quick Commands

```bash
# Clone the repository
git clone https://github.com/JonahSul/mnemosyne-memory-system.git
cd mnemosyne-memory-system

# Install dependencies
npm install

# Set up development environment
npm run dev

# Run tests
npm test

# Deploy to staging
npm run deploy
```

For more detailed information, see the [Development Guide](development-guide.md).
