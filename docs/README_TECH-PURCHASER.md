# Technology Purchaser / Approver README

Audience

Procurement, purchasing, and approvers evaluating vendor and hosting choices.

Key considerations
- Total cost of ownership: factor model/embedding costs, egress, storage, and operational personnel.
- Vendor lock-in: prefer self-hosted or portable storage options where possible.
- Compliance: ensure contracts and hosting locations meet regulatory needs.

Procurement checklist
- Hosting plan requirements (latency, uptime)
- Backup and export SLAs
- Support and maintenance expectations
