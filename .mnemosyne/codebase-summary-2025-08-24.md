This concise summary was generated by the Mnemosyne agent (Athena) while perusing the repository. It captures key architecture points, modules, important files, and actionable observations intended to be consulted before making decisions.

## Project purpose
- Multi-tier memory system providing persistent, verifiable memory, semantic knowledge storage, behavioral rule enforcement, and runtime foundation updates for AI agents.

## High-level architecture
- Durable Object-based MCP server (src/index.ts, src/agent.ts) exposes /sse and /mcp endpoints.
- MnemosyneMemorySystem (src/memory-tool.ts) is the primary memory interface and delegator hub.
- Persistence layers:
  - KV Memory Layer (src/modules/kv-memory-layer.ts) — guaranteed persistence for critical items (protocols, violations, rules).
  - Vector store (CloudflareVectorStore, src/cloudflare-vector-store.ts & src/vector-store.ts) — semantic embeddings, RAG retrieval.
  - Multi-tier memory facade (src/multi-tier-memory.ts, src/modules/tier-mapper.ts) — short/intermediate/long tiers and automated placement.
- Tool registry (src/tools/registry.ts) exposes memory tools to MCP clients.
- Restoration tooling (.mnemosyne/memory-rehydrator.ts, .js) and snapshots (.mnemosyne/memory-state-2025-08-23.json, .mnemosyne/knowledge-store.tmp.json).

## Key files and modules
- src/index.ts — Worker entrypoint; routes and DO binding logic.
- src/agent.ts — Durable Object implementation (MnemosyneMemoryMCP); initializes KV, vector store, tools, and foundation migrations.

- src/modules/kv-memory-layer.ts — KV storage API, health check, critical item retrieval.

- src/tools/terminal-safe-wrapper.ts — terminal wrapper for safe command execution (related to terminal protocols).
- .mnemosyne/ — local snapshots, rehydrator, and agent-maintained journals.

## Notable behaviors & constraints
- Foundation rules are applied at initialization; default rules include 'consult-memory-before-response' and 'no-unverified-claims'.
- KV is used for critical, durable storage of protocols/violations; vector store for semantic retrieval; both are used in recovery/backfill.
- Backfill and restore methods exist and try snapshots before general backfill.
- Tiered writes (memory_store_tiered) were intermittently timing out in prior checks; KV fallback is present and used.
- Terminal handling protocols are documented in .mnemosyne and in knowledge exports; prefer sendCommand over manual terminal creation when possible.
