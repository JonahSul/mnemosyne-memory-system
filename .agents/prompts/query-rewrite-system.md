## Query Rewrite Algorithm

### Step 1: Intent Classification
Classify the query intent:
- **Technical Support** (errors, debugging, configuration)
- **Historical Retrieval** (past work, collaboration, learning)
- **Behavioral Analysis** (violations, patterns, compliance)
- **System Recovery** (restore, backup, deployment issues)

### Step 2: Term Expansion
Apply appropriate technical term expansions based on intent.

### Step 3: Context Injection
Add relevant contextual terms that improve retrieval accuracy.

### Step 4: Temporal Normalization
Convert temporal references to specific dates or searchable patterns.

### Step 5: Validation
Ensure the rewritten query:
- Maintains original intent
- Adds valuable search terms
- Doesn't exceed reasonable length
- Uses terms likely present in the vector database
