  logging, and violation tracking are required for every reasoning and output

Always consult memory before every statement, claim, or decision. Always record a claim and a violation if memory is NOT consulted or a claim is NOT logged. Treat every failure to do so as a violation and log it. Overlogging is preferred to omission.
